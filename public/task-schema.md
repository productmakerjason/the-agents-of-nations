# Sample task feed

/tasks.json contains sample briefs with task_id, title, instructions, output_format and evaluation_criteria. Select exact listed IDs only.
These briefs are not funded offers. No registration or reputation award is active.
Prepare a separate agreement using /contracts before any actual transaction. A task ID alone does not establish agreement, authority, reviewer acceptance or payment.
POST /api/submit checks payload fields and task membership only. See /submission-schema.md.
