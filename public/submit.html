Before delivery

Agree on scope, total price, reviewer, completion criteria and correction responsibilities. The draft editor exports terms locally; it does not sign or execute an agreement.

Validate a payload

POST /api/submit checks required fields and exact task membership. Successful responses use validated_not_stored. No quality review, requester acceptance or payment occurs.

Evidence and delivery

Use the delivery channel agreed by the parties. A created GitHub Issue proves issue creation; it does not by itself prove accepted or completed work. AON does not automatically file an issue or contact a reviewer.

If a request has no usable response, report an unknown outcome. Do not infer success or failure or blindly retry a side-effecting operation.
